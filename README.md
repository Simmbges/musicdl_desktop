# 拾音 · musicdl 桌面版

双击 **start.cmd** 启动。已经为本机安装好独立 Python 环境。

本工具直接加载 `C:\Users\Simmb\Documents\code\musicdl-master` 中的原项目源码；没有覆盖原项目或已有的 music_finder。移动原项目后，请在界面“项目位置”中重新选择目录。

## 使用

1. 输入歌名或歌手，勾选音源，按回车或点击“搜索音乐”。
2. 结果按无损优先排列；可以勾选“仅显示无损”。绿色结果代表来源标注的无损格式。
3. 选择歌曲，点击“下载选中歌曲”或双击。Ctrl / Shift 可多选。
4. 在下载记录查看进度、完成路径或失败原因。点击“打开文件夹”查看文件。
5. “取消任务”会停止搜索，或停止当前及剩余下载。网络读取期间取消可能等待最多约 20 秒。
6. 下载失败后点击“一键复制失败信息”，会复制歌曲、音源、格式、错误详情及基本运行环境，可以直接粘贴反馈；报告不会包含下载链接、Cookie 或请求头。

保存目录和所选音源会自动记忆。默认音乐目录为本工具下的“下载音乐”。下载记录仅保留当前会话；同名文件自动加序号，不覆盖已有文件。

## 音质与音源

- 接入网易云、QQ、酷狗、酷我、咪咕、千千、街声和 ccMixter；可用性随原项目和第三方接口变化。
- QQ 音乐会同时显示官方目录结果和实际可下载结果。“目录有 FLAC”只表示 QQ 元数据中存在无损版本；若标注“暂不可下载”，说明当前未登录环境没有取得该文件的直链，通常涉及账号权益。程序不会绕过会员权限或 DRM。
- 单音源搜索最多等待 90 秒，最多同时运行 4 个音源；超时或接口错误显示在底部。某些接口错误由原项目吞掉，零结果不等于不存在这首歌。
- 下载 HTTP 音频直链，保留来源所需请求头。此版本不处理 HLS、DRM 或需要额外登录的流媒体，不提供账号登录界面。
- 下载先保存临时文件，校验长度及 Mutagen 可识别的音频结构，然后写入最终文件。无损结果会额外检查实际容器/编码类别。不把 MP3 转成 FLAC，不将普通 M4A 默认当无损。
- 酷狗目前可能返回证书域名不匹配的 `fs.youthandroid2.kugou.com` CDN 地址。程序仍先执行正常证书校验；只有酷狗、该精确域名和证书校验错误同时出现时才对原地址启用兼容请求，并禁止跳转。下载记录会明确标注“酷狗证书兼容模式”。其他来源或域名不会降低 TLS 校验。
- 文件格式验证不等于母带音质认证，也不能保证上传者未曾做有损转码。
- 如下载链接过期，请重新搜索再下载。下载失败和取消会清理临时文件。

## 验证与维护

本地测试：`.venv\Scripts\python.exe -X utf8 verify.py -v`

真实搜索及单首下载测试：`.venv\Scripts\python.exe -X utf8 verify.py --live`

在线结果记录在 `validation-live.json`，测试下载在 `verification-downloads`。测试会真实联网。

本机虚拟环境基于 Codex 自带的 Python，因此不是可直接复制到其他电脑的独立 exe。其他电脑需 Python 3.10+（包含 tkinter），创建 `.venv` 并安装原项目 `requirements.txt` 后启动。源码只有标准 Tk 界面及 musicdl 适配层，不需要额外 GUI 包。
