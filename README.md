# 拾音 · musicdl 桌面版

Windows 源码运行需要 Python 3.12 和原项目 [musicdl](https://github.com/CharlesPikachu/musicdl)。在本项目目录打开 PowerShell，执行：

```powershell
git clone https://github.com/CharlesPikachu/musicdl.git ..\musicdl-master
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r ..\musicdl-master\requirements.txt
```

随后双击 **start.cmd** 启动。若已将原项目放在其他位置，可在界面点击“项目位置”选择；程序也兼容原项目位于本项目上两级目录的布局。运行后会在本地生成 `settings.json`，其中保存个人路径和偏好，不上传到仓库。

运行 `build.ps1` 可在本地生成 `dist\Shiyin.exe`。单文件 EXE 包含 Python、musicdl 源码和依赖；首次启动需要等待解压，并应与同目录的 `LICENSE-musicdl.txt` 一起分发。

不想自行构建可从 [GitHub Releases](https://github.com/Simmbges/musicdl_desktop/releases) 下载 Windows 版 EXE 和对应的许可文件。

## 使用

1. 输入歌名或歌手，勾选音源，按回车或点击“搜索音乐”。
   “每个音源最多”可以从下拉建议中选择，也可以手动输入任意正整数；设置会自动保存。实际返回数量可能少于设定值，数字越大搜索可能越慢。
2. 所有音源在搜索阶段都只获取并显示目录词条，不会提前解析下载地址。选择歌曲并点击下载后，程序才解析该词条对应的真实地址。
3. 结果按无损优先排列；可以勾选“仅显示无损”。绿色结果代表来源标注的无损格式。
   “预计大小”来自音源目录提供的各音质版本信息；点击下载后才确定实际版本，最终文件可能略有差异。
4. 单击歌曲词条即可选中，再点同一首会取消选中；依次点击多首可批量选择，不必按 Ctrl / Shift。“全选当前结果”和“取消全部选择”可快速调整。选好后点击“下载最高无损”，也可选中一首点击“选择音质…”。程序会在点击下载后才解析地址；选择音质时只列出取得无损下载地址的档位。接口没有标明档位时会显示“自动解析（档位未标明）”。即使其他音源仍在搜索，程序也会先停止剩余搜索再处理所选歌曲。
5. 在下载记录查看进度、完成路径、FLAC 实际位深与采样率或失败原因。点击“打开文件夹”查看文件。
6. “取消任务”会停止搜索，或停止当前及剩余下载。网络读取期间取消可能等待最多约 20 秒。
7. 下载失败后点击“一键复制失败信息”，会复制歌曲、音源、格式、错误详情及基本运行环境，可以直接粘贴反馈；报告不会包含下载链接、Cookie 或请求头。

保存目录和所选音源会自动记忆。默认音乐目录为本工具下的“下载音乐”。下载记录仅保留当前会话；同名文件自动加序号，不覆盖已有文件。

相同关键词、音源、模式和数量的搜索结果会在当前会话缓存 15 分钟。快速模式下，某个音源连续失败两次后会冷却 10 分钟，避免反复等待；完整模式仍会尝试该音源。音源按酷我、网易云、酷狗、QQ、咪咕、千千、街声、ccMixter 的顺序优先调度，最多同时运行 4 个。

## 音质与音源

- 接入网易云、QQ、酷狗、酷我、咪咕、千千、街声和 ccMixter；可用性随原项目和第三方接口变化。
- 所有音源搜索时只显示目录元数据；“目录有无损”表示来源元数据声称存在无损版本，实际格式要等点击下载并解析后才能确定。QQ 等音源可能受账号权益限制，程序不会绕过会员权限或 DRM。
- 单音源搜索最多等待 90 秒，最多同时运行 4 个音源；超时或接口错误显示在底部。某些接口错误由原项目吞掉，零结果不等于不存在这首歌。
- 点击下载后才解析并访问真实地址，同时保留来源所需请求头。StreetVoice 的 HLS 音频会在解析阶段完成分段下载；不处理 DRM 或需要额外登录的流媒体，不提供账号登录界面。
- 下载先保存临时文件，校验长度及 Mutagen 可识别的音频结构，然后写入最终文件。无损结果会额外检查实际容器/编码类别。不把 MP3 转成 FLAC，不将普通 M4A 默认当无损。
- “最高无损”仅在当前接入接口实际能返回的版本中选择；不同来源的档位不完全可比，文件更大不等于原始录音更好。选择列表中的大小是解析接口给出的预计值，下载后以文件实际规格为准。
- 下载 FLAC 时会补齐缺失的歌曲名、歌手和专辑标签；来源提供封面时嵌入图片，提供歌词时写入 `LYRICS` 标签。复制到椒盐音乐时只需复制 FLAC 文件。来源没有提供封面或歌词时不会自动猜测，原有标签和封面也不会被覆盖。
- 酷狗目前可能返回证书域名不匹配的 `fs.youthandroid2.kugou.com` CDN 地址。程序仍先执行正常证书校验；只有酷狗、该精确域名和证书校验错误同时出现时才对原地址启用兼容请求，并禁止跳转。下载记录会明确标注“酷狗证书兼容模式”。其他来源或域名不会降低 TLS 校验。
- 文件格式验证不等于母带音质认证，也不能保证上传者未曾做有损转码。
- 如下载链接过期，请重新搜索再下载。下载失败和取消会清理临时文件。

## 验证与维护

本地测试：`.venv\Scripts\python.exe -X utf8 verify.py -v`

真实搜索及单首下载测试：`.venv\Scripts\python.exe -X utf8 verify.py --live`

在线结果记录在本地 `validation-live.json`，测试下载在 `verification-downloads`；这些产物不会上传到仓库。测试会真实联网。

需要重新打包时，先运行 `.\.venv\Scripts\python.exe -m pip install pyinstaller`，再运行 `powershell -ExecutionPolicy Bypass -File .\build.ps1`。输出位于 `dist\Shiyin.exe`。源码方式启动需要 Python 3.12（包含 tkinter）和原项目依赖。
